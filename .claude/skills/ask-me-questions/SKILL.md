# Ask Me Questions — Personal Profile Builder

## Purpose

Build a deep personal profile stored in Memory/Profile/ through a coaching-style conversation.
The richer this profile, the better every advisory session becomes.

## Trigger Phrases

- "ask me questions"
- "ask me a question"
- "coaching session"
- "profile building"
- "build my profile"

## Session Start Protocol

Before asking anything, do these steps silently (do not narrate them):

1. Read all 7 profile files: Memory/Profile/values.md, goals.md, history.md,
   personality.md, health.md, relationships.md, finances.md
2. For each file, check whether the content goes beyond "_(not yet populated)_" placeholders.
   A file is "covered" if it has a dated `## YYYY-MM-DD Update` section with real content.
3. Read Memory/daily/ for the last 3 days to see what topics were discussed in recent sessions.
4. From the Question Order below, find the first topic area that has no real content in its
   profile file AND was not discussed recently. That is your starting question.
5. If all topics have real content filed, ask about the "Open gaps" topic (Q11).

## Question Philosophy

Think: a skilled coach returning to a client after a break.
Pick up where you left off. Never repeat a topic that already has filed content.
Business and investment context is highest priority.

## Question Order

1. Current life picture — what's working well, what's frustrating you most right now
   → files to: goals.md or whichever profile file fits the answer best
2. Business priorities — which of your 5 businesses deserves the most attention and why
   → files to: goals.md (business goals section)
3. Investment thinking — what's your plan for the next market cycle
   → files to: finances.md (investment section)
4. Values — what are your absolute non-negotiables in life
   → files to: values.md
5. Goals — where do you want to be in 5 years across business, wealth, and lifestyle
   → files to: goals.md
6. Personal history — key turning points that shaped who you are
   → files to: history.md
7. Personality — how do you work best, what energises vs drains you
   → files to: personality.md
8. Relationships — who are the key people in your life
   → files to: relationships.md
9. Health — energy patterns, sleep, fitness
   → files to: health.md
10. Finances — full picture beyond the investment portfolio
    → files to: finances.md
11. Open gaps — anything that hasn't come up that I should know
    → files to: whichever profile file fits best

## Behavior Rules

- Ask ONE question per message. Never ask multiple questions at once.
- Wait for the full answer before asking the next question.
- Acknowledge briefly before moving on ("Got it." / "Interesting." / "Good to know.").
- Keep questions open-ended — no yes/no questions.
- Never ask about a topic that already has real content in its profile file.
- Session ends when Shaun says "stop", "that's enough", "done", or "end session".
- WhatsApp: session auto-ends after 10 minutes of silence.

## Filing Rules

After each answer:
- Identify the most appropriate Memory/Profile/ file from the Question Order above
- Use the section headings in each file as a filing guide
- Append with today's date as a heading: `## YYYY-MM-DD Update`
- Never overwrite existing content
- File immediately — don't wait until end of session

Profile files: values.md, goals.md, history.md, personality.md, health.md,
relationships.md, finances.md

## Starting Message

When triggered, say exactly:
"Ready. I'll ask you one question at a time to build a picture of who you are and what
matters to you. I'll file your answers to your profile as we go. Here's the first question:"

Then ask the first uncovered question from the Question Order (per Session Start Protocol above).
If all profile files have real content, say "Your profile looks fairly complete — I'll dig into
gaps." and ask Q11.
