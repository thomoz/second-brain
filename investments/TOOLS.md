# Investments Tools — What Runs, When, and How to Run It Now

Three packages share `investments/briefs-finance/data/investments.db`: **my-trader**
(personal Find/Monitor engine), **briefs-finance** (Briefs Finance report scoring),
and **goat** (sector-rotation/momentum tool). This doc lists every tool, whether
it's automated or manual, and the exact command to run it on demand.

Auto-generated by hand 2026-08-17, last updated 2026-08-18 — update this file
whenever a tool's schedule or command changes; it isn't regenerated automatically.

## Automated (scheduled)

| Tool | What it does | Where it runs | Schedule |
|------|--------------|----------------|----------|
| **my-trader Monitor** | Re-checks all holdings + vetted watchlist rows | Windows Task Scheduler (`SecondBrain-MyTraderMonitor`), this dev machine | Daily, 7:30am Sydney local |
| **Goat Monitor** (150DMA exit check + sector rotation scan) | Flags holdings closing below their 150-day MA; ranks the 11 SPDR sector ETFs and stages fresh breakout candidates | VPS systemd (`second-brain-goat-monitor.timer`) | Daily, 21:35 UTC (07:35 AEST / 08:35 AEDT — fixed UTC time, so the Sydney clock time shifts by an hour across DST) |
| **Goat Intraday Live-Check** | Live-price 150DMA check against currently-open-market holdings (ASX or US session) | VPS systemd (`second-brain-goat-live-check.timer`) | Every 10 minutes, around the clock (no-ops outside ASX/US regular session hours, so it's cheap off-hours) |
| **Goat Heartbeat Scan** (S&P 500) | Screens S&P 500 constituents in currently-rising sectors for the low-volatility-consolidation-then-breakout "heartbeat" pattern, with fundamentals survival context attached | VPS systemd (`second-brain-goat-heartbeat-scan.timer`) | Weekly, **Saturday 8:00am Sydney local** (timezone-aware, stays correct across DST) |
| **Goat Insider Scan** (OpenInsider) | Checks P/S Form 4 filings on current holdings (Holdings Watch), and stages market-wide $25k+ open-market insider buys as new watchlist candidates (Discovery). Every pending/tracked ticker also gets a **price-since-trade-date** figure, recalculated fresh each run, 🚩-flagged when the move confirms the insider's signal direction (buy → price up, sale → price down) by 15%+; past 90 days it's annotated as possibly stale rather than hidden | VPS systemd (`second-brain-goat-insider-scan.timer`) | Daily, 21:50 UTC (07:50 AEST / 08:50 AEDT — fixed UTC time, runs ~15min after Goat Monitor) |
| **Fourteen Crash Signals Daily Check** | Tracks 8 of the 14 crash-warning markers (credit spread streak + watch tier, margin debt YoY, insider selling trend, market-cap milestone, off-balance-sheet leases, capex-vs-cash-flow, Super Bowl ad-share reminder, credit spread divergence) against a dynamically-recomputed hot-company watchlist; other 6 markers pending future phases. Marker #12's bond-yield lookup is currently manual-entry only (`record-bond-yield` subcommand) -- no working free live-scrape source was confirmed as of the Phase 2 build | VPS systemd (`second-brain-fourteen-signals.timer`) | Daily, 22:05 UTC |

## Manual / on-demand only

| Tool | What it does | Command |
|------|--------------|---------|
| **my-trader Find** | Conversational ticker assessment against your 7 checks + Briefs Finance's likelihood score | `uv run --directory investments/my-trader python -m mytrader.main find --ticker TICKER` (also invoked conversationally via the `my-trader` skill) |
| **my-trader watchlist ops** | Add/remove/move a watchlist ticker | `mytrader.main watchlist-add / watchlist-remove / watchlist-move-bucket` |
| **my-trader holding ops** | Record a buy/sell against a holding | `mytrader.main holding-buy / holding-sell` (also conversational via the skill) |
| **my-trader snapshot** | Regenerate `holdings.md` / `watchlist.md` from the DB | `uv run --directory investments/my-trader python -m mytrader.main snapshot` |
| **my-trader IBKR sync** | Read-only diff of your real IB Gateway positions against tracked holdings — local-only, never scheduled, never touches the account | `uv run --directory investments/my-trader python -m mytrader.main sync-ibkr` (add `--apply` to commit corrections; see `ibkr-setup-guide.md`) |
| **Goat sector scan (on-demand)** | Same sector-rotation ranking + breakout check the daily Monitor runs, without the 150DMA holdings check | `uv run --directory investments/goat python -m goat.main scan-sectors` |
| **Goat live-check (on-demand)** | Same intraday 150DMA check the timer runs, right now | `uv run --directory investments/goat python -m goat.main check-live` |
| **Goat heartbeat scan (on-demand)** | Same S&P 500 heartbeat scan the weekly timer runs, right now — doesn't wait for Saturday | `uv run --directory investments/goat python -m goat.main scan-heartbeat` |
| **Goat insider scan (on-demand)** | Same OpenInsider holdings-watch + discovery scan (with price-since-trade tracking) the daily timer runs, right now | `uv run --directory investments/goat python -m goat.main scan-insiders` |
| **Goat Hormuz risk scan (on-demand)** | Strait of Hormuz war-risk check -- BWET (tanker freight ETF, proxy for TD3C) price move over 14 days, flagged at 15%+ either direction; LMA Joint War Committee "Listed Areas" circular number, flagged when it changes since the last check. Reports raw detail/excerpt, not an auto-classified escalation/de-escalation verdict -- not yet on a scheduled timer, manual only | `uv run --directory investments/goat python -m goat.main scan-hormuz` |
| **Goat promote/dismiss candidate** | Move a staged Goat candidate (sector ETF, heartbeat stock, or insider-buy discovery) into my-trader's real watchlist, or discard it | `goat.main promote-candidate --ticker TICKER` / `goat.main dismiss-candidate --ticker TICKER` |
| **Briefs Finance ingest** | Ingest a PDF report into the scoring pipeline | `uv run --directory investments/briefs-finance python -m scripts.main ingest ...` (also conversational: "ingest this report") |
| **Briefs Finance backtest** | Backtest historical recommendations against real market data | `scripts.main backtest` |
| **Briefs Finance score** | Compute 0–100% likelihood scores for new recommendations | `scripts.main score` |
| **Briefs Finance assess / context / stats / excluded** | Full ticker assessment / sector+macro context / track-record summary / defense-filtered exclusion list | `scripts.main assess --ticker TICKER` / `context` / `stats` / `excluded` |
| **Fourteen Crash Signals (on-demand)** | Same daily check the timer runs, right now | `uv run --directory investments/fourteen-crash-signals-daily-check python -m fourteen_crash_signals_daily_check.main daily-check` |
| **Fourteen Crash Signals: record bond yield** | Manually record a bond yield reading for Marker #12 (no working free live-scrape source is available as of the Phase 2 build) | `uv run --directory investments/fourteen-crash-signals-daily-check python -m fourteen_crash_signals_daily_check.main record-bond-yield TICKER YIELD_PCT [--cusip CUSIP]` |

Run any `investments/goat` or `investments/my-trader` command from the repo root with
`uv run --directory investments/<package> python -m <module> <subcommand>`. On the
VPS, the same commands run via each systemd `.service`'s own venv
(`investments/.venv/bin/python`).

## Notes on the schedule mismatch

my-trader's own Monitor timer exists on the VPS (`second-brain-mytrader-monitor.timer`)
but is deliberately left **disabled** there — my-trader Monitor still runs on this
Windows machine via Task Scheduler instead, to avoid double-running the same check
from two places. If my-trader Monitor is ever migrated to the VPS, disable
`SecondBrain-MyTraderMonitor` on Windows first, the same way Heartbeat/Reflection/
WhatsAppBot were disabled after the VPS went live (see root `CLAUDE.md`).
