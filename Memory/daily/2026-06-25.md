- PCDJ/Karaoki looks stronger on tight host workflow: rotation, singer history, key-change memory, drag/drop, and remote requests feeding straight into the live hosting flow.
- KaraFun looks stronger on polish and discovery: modern UX, playlists, top/new songs, genre browsing, quizzes/games. That raises user expectations even if they’re not your exact B2B competitor.
- Your biggest visible weakness is the one already in memory: onboarding friction. If setup/import/update/request flow feels even a bit harder than competitors, DJs will assume switching risk is high.
- The desktop-app/code-signing blockage is also strategic. Even if SBDB’s core is good, “feels old / risky / maybe abandoned” is enough to push users to newer-looking options.

My read on the actual risk:
- I do not think you’re most exposed to a rival “building a better database”.
- I think you’re exposed to someone making the whole KJ workflow feel easier, more modern, and more automated.

How AI changes this industry:
- Natural-language song search becomes standard: “that country breakup song about whiskey” should work.
- Auto-tagging and metadata cleanup get much better, which reduces the value of manual catalog maintenance.
- Request systems will become assistant-like: smart suggestions, duplicate detection, rotation-aware recommendations, “you sang this last week”.
- Onboarding gets compressed hard: import library, clean names, detect dupes, generate songbook, publish, done.
- Hosts will expect AI to reduce admin, not just add chatbot fluff.

How you can capitalise:
- Make SBDB the easiest migration product in the market. “Import anything, clean everything, go live in 10 minutes.”
- Build AI around workflow, not novelty:
  AI import cleaner
  AI duplicate/quality matcher
  AI song search from vague prompts
  AI onboarding assistant
  AI request triage for hosts
  AI “what should I buy” catalog gap detector
- Position SBDB as the neutral control layer for KJs. Not just a songbook: request intake, catalog cleaning, singer memory, venue-level insights.
- Lean into the installed base you already have. You do not need magic. You need less friction, faster time-to-value, and obvious weekly improvements.
- If I were prioritising, I’d do this order: onboarding assistant, smarter import cleanup, better mobile request UX, then host-side intelligence.

Bluntly: AI probably helps you if you use it to remove setup pain and host admin. It hurts you if you wait, because then competitors turn “songbook software” into “autopilot for karaoke hosting”.
