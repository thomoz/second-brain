**[Brain]** Yes.

My take: the hardest thing to learn is not one screen. It’s the setup model.

What looks hard:
The user has to understand too many moving parts up front: Dashboard, Pal, singer app, kiosk, Mobile Requests Hoster, and possibly PCDJ or MTU plugins. That’s a lot before they get a first win. Source: https://www.songbookdb.com/docs2/songbookdb-full-documentation-for-djs.php

The setup path is fragile. The quick start says install Harman AIR first, then Pal, then maybe a plugin, and if you use PCDJ or MTU the process is different enough that doing it wrong means requests will not load. Source: https://www.songbookdb.com/docs2/songbookdb-quick-start-set-up-for-djs.php

The terminology adds cognitive load. “Rigs” is powerful, but not obvious for a new DJ. They also have to grasp venues, gigs, song lists, requests logins, kiosk logins, and rig-to-gig assignment before the system feels simple. Source: https://www.songbookdb.com/docs2/songbookdb-pal-documentation.php and https://www.songbookdb.com/docs2/songbookdb-dj-dashboard.php

The documentation itself is reasonably thorough, but it feels fragmented. A new user has to choose between 60-second overview, quick start, full docs, and many videos, and then figure out which path applies to them.

So my answer is:
The biggest learning problem is onboarding architecture more than missing documentation. The docs explain things, but the product asks the user to build the whole mental model too early.
